# KeyCraft Frontend

A modern full-stack mechanical keyboard e-commerce platform built with Next.js, TypeScript, Redux Toolkit, and Stripe integration.

## Live Features

- Modern responsive UI
- Product filtering & search
- Wishlist system
- Cart functionality
- Stripe payment integration
- User authentication
- Protected routes
- Admin dashboard
- Order history
- Mobile-first design
- Role-based navigation

---

# Tech Stack

## Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Redux Toolkit
- RTK Query
- Framer Motion
- Lucide React
- Zod Validation

## Payment
- Stripe Checkout

---

# Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=your_key
```

---

# Installation

```bash
git clone <git@github.com:Priyanka-Das-Dipa/mechanical_keyboard_shop_client.git>

cd mechanical_keyboard_shop_client

npm install
```

---

# Run Development Server

```bash
npm run dev
```

---

# Build For Production

```bash
npm run build
```
